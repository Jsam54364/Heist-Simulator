# Character asset credits

Bodies, morph targets, proxy meshes (male1591, female1605), clothes (casual/elegant/sport suits),
shoes, hair (short01/02/04, afro01, ponytail01, bob02, long01), eyebrows (eyebrow001),
eyelashes (eyelashes01), eyes (low-poly, brown, brownlight), skins (young caucasian / african /
asian, male and female) and the default skeleton weights are from **MakeHuman**
(http://www.makehumancommunity.org), released under **CC0 1.0** by Data Collection AB,
Joel Palmius and Jonas Hauquier (2020). No attribution is required; this note is a courtesy.

Fitting, rigging, rest-pose normalisation, garment splitting/recolouring, atlas packing, gear
(hats, helmet, balaclava, vest, duty belt, sunglasses) and all animation clips were made for this
game in `tools/blender/`. The player and partner faces are projected from the project's own
reference sheets (`tools/reference/`).
